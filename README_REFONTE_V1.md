# Sanctuaire des Oracles — Refonte graphique V1 (six oracles)

Cette archive est un prototype visuel transversal basé sur la version V10 fournie dans le dossier de travail.

## Contenu
- Les six pages d'oracle existantes sont conservées : Tarot, Belline, Grand Lenormand, Astrologie, Runes et Portes de l'Intuition.
- Une identité graphique sombre, or et violet est appliquée à l'ensemble.
- Six emblèmes SVG originaux et différenciés sont intégrés dans l'accueil et dans chaque page.
- Les pages d'analyse croisée, de réglage de clé API et les ressources PWA du socle V10 sont conservées.
- Les fichiers d'origine des pages sont modifiés uniquement pour ajouter la feuille de style et les éléments visuels.

## Installation de test
1. Créer une branche séparée, par exemple `refonte-visuelle-v1`.
2. Décompresser toute l'archive.
3. Envoyer tous les fichiers et le dossier `assets/` à la racine de cette branche, en conservant l'arborescence.
4. Configurer GitHub Pages temporairement sur cette branche pour tester, sans toucher à V11.0.

## Limites connues
Ce livrable est une première refonte graphique cohérente pour les six oracles, pas la livraison finale promise : les emblèmes sont des illustrations vectorielles d'ambiance, pas encore 78 peintures de cartes Tarot ni un jeu complet de cartes illustrées uniques pour chaque oracle. Les fonctions héritées sont conservées dans les fichiers, mais elles doivent être testées dans le navigateur et avec une vraie clé API avant publication.
