INSTALLATION GITHUB MOBILE — V6.0

Aucun dossier assets n'est nécessaire : le moteur d'illustration est intégré aux six pages HTML.

1. Décompresser le ZIP.
2. Téléverser les fichiers à la racine de la branche V5.2 (remplacer les versions existantes).
3. Vérifier que sw.js est également remplacé : son cache passe en v6.0.
4. GitHub Pages doit publier la branche V5.2 à la racine (/).

Après publication, fermer complètement l'application installée ou le navigateur, puis rouvrir le site. Si l'ancien écran persiste, désinstaller le raccourci/PWA puis réinstaller après vérification du site web.
