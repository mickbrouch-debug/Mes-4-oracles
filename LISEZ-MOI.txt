ORACLES STUDIO — HARMONISATION V1

Cette archive contient :
- sanctuaire-unifie-v1.css : couche graphique commune inspirée du Tarot ;
- appliquer_harmonisation.py : script qui applique la feuille aux six oracles et répare une corruption HTML connue.

IMPORTANT
1. Cette archive n'est pas encore publiée sur GitHub.
2. Le script doit être lancé dans le dossier contenant les fichiers HTML de la branche V5.
3. Il modifie uniquement :
   portes-intuition.html
   belline.html
   astrologie.html
   lenormand-54.html
   Grand_Jeu_Mlle_Lenormand_54.html
   runes.html
4. Il ne modifie ni index.html ni tarot-78.html.
5. Il conserve les scripts et les fonctions de chaque oracle ; il ajoute une feuille CSS finale et corrige le texte de balise nav mal formé.
6. Il crée ORACLES_HARMONISES_V1.zip à la racine du dossier, avec les six pages, la feuille CSS et la bannière si elle est présente.

Prérequis : Python 3.8 ou supérieur.
Commande : python appliquer_harmonisation.py
Ou : python appliquer_harmonisation.py "chemin/vers/le/dossier/V5"

Après génération, téléverser les fichiers de ORACLES_HARMONISES_V1.zip à la racine du dépôt GitHub, en conservant sanctuaire-banniere.jpg à la racine.
