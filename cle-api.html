Clé API Gemini commune

Enregistre ici une seule clé pour les six oracles et l'analyse croisée. Chaque oracle pourra l'utiliser automatiquement, tout en conservant la possibilité d'une clé individuelle si tu en renseignes une dans ses réglages.

Clé API partagée

La clé est enregistrée uniquement dans le stockage local de ce navigateur. Elle n'est pas ajoutée aux fichiers GitHub. Ne la partage pas et ne la publie jamais dans le dépôt.
